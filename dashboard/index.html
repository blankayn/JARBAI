Setup

Cloud brain — Google AI Studio

Faster replies and better transcription, but needs internet and your commands are sent to Google. Optional — JARBAI runs fully offline without it.

  1. Open aistudio.google.com/apikey and sign in
  2. Click Create API key — the free tier is enough
  3. Copy it and paste below
Stored in .env, never committed to git.

Local brain — Ollama

Private and works with no internet. Slower on a laptop CPU.

  1. Install from ollama.com/download
  2. Run ollama pull qwen2.5:3b
  3. Leave it running — JARBAI starts it automatically

New machine?

Copy this folder over, then run setup.ps1 in PowerShell. It creates the virtualenv, installs everything, makes the icon and adds the desktop shortcut. Paste your API key here afterwards.
